# Third-party notices

The Windows installer bundles MinGit from Git for Windows `v2.56.0.windows.2` so Git-based project views work without a separate Git installation. The upstream release and source are available at:

- https://github.com/git-for-windows/git/releases/tag/v2.56.0.windows.2
- https://github.com/git-for-windows/git

MinGit's top-level `LICENSE.txt` and the license files for bundled components are included under the installed application's `resources/git` directory. Those components remain under their respective upstream licenses. The MinGit archive SHA-256 is pinned and checked by `scripts/prepare-toolchain.mjs`.
